# ILYA | إيليا — Luxury Women's Fashion E-Commerce Platform (AR / TR)

متجر إلكتروني احترافي ثنائي اللغة (العربية RTL / التركية LTR) مخصص لعلامة الأزياء النسائية التركية **ILYA | إيليا**.

## المميزات الأساسية (Core Features)
1. **ثنائي اللغة بالكامل (AR / TR)**: تبديل فوري بين العربية (من اليمين لليسار بخط IBM Plex Sans Arabic / Tajawal) والتركية (من اليسار لليمين بخط Poppins / Inter).
2. **إدارة الكتالوج والتصنيفات بدون برمجة**: 10 تصنيفات أساسية قابلة للتعديل والإضافة والحذف، مع إمكانية تفريغ المنتجات التجريبية بضغطة زر واحدة وإضافة منتجات وصور حقيقية.
3. **نظام المفضلة وتنبيهات انخفاض الأسعار (Price Drop Alerts)**: اشتراك العميلات في تنبيهات انخفاض السعر لكل منتج، وإرسال إشعارات تلقائية عند تخفيض السعر من لوحة التحكم.
4. **سلة تسوق وCheckout متوافق مع التجارة الإلكترونية التركية**: تعديل المقاس واللون والكمية داخل السلة، حساب الكوبونات والشحن، والامتثال لمتطلبات `KVKK` و`Mesafeli Satış Sözleşmesi`.
5. **بنية جاهزة لبوابات الدفع التركية (iyzico & PayTR)**: نقاط نهاية برمجية (`backend/server.js`) جاهزة لاستقبال مفاتيح التاجر الحقيقية دون بيانات دفع وهمية.

## التشغيل والنشر (Deployment)
```bash
cp .env.example .env
npm install
npm start
```
أو باستخدام Docker:
```bash
docker-compose up -d --build
```
